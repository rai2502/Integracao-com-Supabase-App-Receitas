Quando o app vira nativo

Esses botões só existem de verdade dentro da ponte do Capacitor.

Em um navegador comum, JavaScript não acessa a câmera do sistema nem o GPS diretamente com essa liberdade. É o Capacitor quem expõe esses recursos nativos para o código web, através de plugins.
